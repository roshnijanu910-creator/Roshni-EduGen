# EduGenie

EduGenie is an AI-powered learning assistant built with:

- FastAPI
- Google Gemini
- HTML
- CSS
- JavaScript
- Pydantic
- Pytest

## Features

### Ask EduGenie

Ask educational questions and receive explanations adapted to the selected learning level.

### Summarize

Paste study material and receive a simplified summary.

### Quiz Generator

Generate quizzes with:

- Topic
- Number of questions
- Difficulty
- Learning level

### Personalized Learning Path

Create a week-by-week learning plan based on:

- Learning goal
- Current level
- Number of weeks

### Recommendation API

Generate learning recommendations for a selected topic and level.
